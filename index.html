04 // PRATIQUE RÉELLE EN B1

Ce que je pratique concrètement

L'informatique ne s'apprend pas dans les livres, elle se pratique les mains dans le terminal. Au quotidien à l'EPSI, je construis mon socle technique en configurant, testant et sécurisant des environnements réels.

Linux & Administration Système
  • • Distributions : Pratique sur Rocky Linux 9 et Debian en machine virtuelle.
  • • Gestion système : Droits d'accès (chmod/chown), arborescence UNIX, gestionnaires de paquets.
  • • Services : Démarrage et supervision via systemctl (serveur web Apache, pile réseau).
  • • Automatisation : Écriture de scripts Shell / Bash pour industrialiser les configurations.
Réseau & Hyperviseurs
  • • Modèle OSI & Protocoles : Compréhension des 7 couches du modèle OSI, segmentation des trames et paquets TCP/IP.
  • • Virtualisation : Déploiement et gestion d'hyperviseurs sous Proxmox VE et VMware.
  • • Routage & NAT : Activation du relayage IP (sysctl ip_forward) et passerelles locales.
  • • Configuration réseau : Paramétrage d'interfaces via NetworkManager et nmcli.
  • • Plan d'adressage : Modélisation de schémas réseau (Dia / Visio), calcul de masques et sous-réseaux.
Productivité, IA & Organisation
  • • Agents IA & Intégration Obsidian : Application directe de mon approche harness (règles système, interactions avec mon coffre Obsidian, assistance au code et structuration des connaissances).
  • • Obsidian (Expert) : Prise de notes méthodique de mes cours et TP en Markdown, personnalisation de thèmes CSS avancés et structuration des connaissances.
  • • Git & GitHub : Versionnage de code rigoureux, gestion de dépôts et hébergement via GitHub Pages.
  • • Hardware PC : Montage complet, diagnostic matériel et optimisation de postes de travail.
